Installer SGC Organisation

  1. Sur Android, ouvrir l’adresse HTTPS privée qui aura été approuvée dans Chrome.
  2. Attendre le chargement complet puis choisir Installer l’application dans Chrome, ou utiliser le bouton lorsqu’il est proposé.
  3. Vérifier l’icône SGC et lancer depuis l’écran d’accueil.
  4. Créer des données fictives, fermer, rouvrir puis tester hors ligne et sauvegarde/restauration.

Aucun hébergement n’est activé. 127.0.0.1 sur le téléphone désigne le téléphone, pas votre PC. Les données PC ne se transfèrent pas automatiquement vers une autre adresse ou un autre appareil.

Le cache garde le code, pas une sauvegarde des sociétés et tâches. Gardez une copie externe vérifiée.
